# Activation Center Design Canon

The center is an operating instrument, not a celebratory dashboard.

- Cyan identifies the current actionable gate.
- Green is reserved for evidence-backed passes.
- Gold identifies evidence required.
- Muted states are locked by predecessor order.
- Plain language accompanies every governance identifier.
- All controls must work with keyboard, touch, reduced motion, and narrow screens.
- Retry reevaluates; it never manufactures evidence.
- Defer preserves the continuation; it never advances state.
- No percentage is displayed because the program is ordered and evidence-gated.
