# XAO-010 Design Canon

- Evidence is identified by contract, not acronym alone.
- **ACCEPTED** is reserved for a contract-matching receipt that meets the minimum certification level.
- **HELD** is a safe state, not an error or a completion claim.
- The source repository, commit, candidate count and collision count remain visible.
- Green may communicate accepted evidence; gold communicates the current actionable gate.
- Recovery names the artifact required next and never exposes credentials or raw logs.
- Retry reevaluates the governed receipt; it does not fetch privately or manufacture evidence.
- XRI-007 cannot appear as current until canonical XRI-006 evidence is accepted.
