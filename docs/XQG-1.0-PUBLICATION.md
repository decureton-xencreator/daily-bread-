# Meet Xen Quality Guardian

Making a mistake should improve a coaching session—not end it.

Quality Guardian adds an explicit recovery route to every Academy answer: correct and
retry, ask for a focused hint, or continue and revisit the unfinished activity before
completion. It also checks Xen controls and records privacy-safe local signals for
repeated clicks, failed recovery contracts, and runtime errors.

Your answers, private text, passwords, and raw printable keystrokes are excluded.
Diagnostics stay in your browser and can be deleted with Reset local data.

XQG 1.1 extends that protection across the complete Daily Bread Command Deck. All 14
scenes, global navigation, Voice controls, links, and embedded media now belong to a
live surface registry. When a new interface element is rendered, Guardian checks it
again automatically. Intentionally read-only scenes are identified as such; interactive
scenes cannot quietly lose their expected controls.
