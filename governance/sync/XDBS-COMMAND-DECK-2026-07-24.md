# XDBS Command Deck synchronization

Daily Bread XPS 4.0 replaces the scrolling dashboard composition with the Xen Command Deck scene system.

## Inherited design rules

- One dominant scene at a time.
- Narrative progression with persistent counter and progress rail.
- Restrained chrome, deep negative space and cyan/green proof states.
- Back, next, keyboard and index navigation.
- Mobile is a composed stage, not a compressed desktop dashboard.

## Preserved capability rules

Academy, intelligence, Integration Process, XMI, Mission Control, Warden diagnostics, provenance, archive and local persistence remain functional. The immutable July 24 archive is unchanged.

## Privacy

No raw chat, private repository material or sensitive personal state is promoted into public source.
